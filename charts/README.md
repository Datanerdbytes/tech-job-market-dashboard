# Compensation by role and work arrangement — tech_job_market

Deliverables for the hiring-demand and compensation analysis.

| File | What it is |
|---|---|
| `compensation_by_role_and_arrangement.html` | Interactive Plotly chart (hover for per-cell posting counts and disclosure rates) |
| `compensation_by_role_and_arrangement.png` | Static export of the same figure |
| `compensation_by_role_and_arrangement.csv` | The exact data the chart is built from |
| `comp_by_role_arrangement.sql` | Verbatim SQL used for every number in the chart and the write-up |
| `build_compensation_chart.py` | Reproducible build script |

## Regenerating

```sh
export TECH_JOB_MARKET_DSN='postgresql://postgres:<pw>@localhost:5432/tech_job_market'
python charts/build_compensation_chart.py --png
```

Requires `plotly`, `pandas`, `psycopg2-binary` (and `kaleido` for `--png`).

## Provenance

All SQL was generated by the **Auto-Ontology semantic layer** (the text-to-SQL agent
against the compiled glossary for `tech_job_market`) and then independently re-run
against the dbt target to confirm the rows matched exactly. See the header comments in
`comp_by_role_arrangement.sql` for the run-by-run receipt, including one query that
returned a wrong result set and how it was caught and corrected.
